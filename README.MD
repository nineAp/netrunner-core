# Netrunner Core

Netrunner Core — это высокопроизводительный сетевой комплекс, реализующий TLS-туннелирование с мультиплексированием потоков для обхода сетевых ограничений. Система состоит из легковесного клиента (поддерживающего Android и Linux) и серверной части.

## Архитектура

Проект построен на принципах:

- Мультиплексирование: Несколько SOCKS5-сессий передаются внутри одного TLS-туннеля.
- TLS-обфускация: Маскировка трафика под стандартный HTTPS.
- Кроссплатформенность: Ядро на Rust, готовое к интеграции в мобильные (Android) и десктопные системы.

## Основные компоненты

- core/: Общая сетевая логика, протоколы и кодек шифрования.
- client/: Клиентское приложение для проброса трафика.
- server/: Серверная часть, принимающая туннели.
- tools/: Утилиты для генерации связующего кода (Android/Kotlin) и логирования.

## Быстрый старт

### Требования

- Rust (latest stable)
- cargo-ndk (для Android-сборки)

### Локальная разработка

# Запуск клиента в режиме отладки

make debug-client

# Запуск сервера локально (порт 4443)

make debug-server

## Деплой сервера

1. Настройте IP сервера в Makefile (переменная SERVER_IP).
2. Подготовьте удаленную машину:
   make setup-server
3. Соберите и деплойте сервер:
   make build-server
   make deploy-server

## Команды Makefile

| Команда            | Описание                                                   |
| :----------------- | :--------------------------------------------------------- |
| make build-android | Сборка библиотек для всех ABI и генерация Kotlin-биндингов |
| make deploy-server | Сборка, копирование бинарника и обновление systemd-сервиса |
| make logs          | Просмотр логов удаленного сервера                          |
| make ssh           | Быстрый вход на сервер                                     |
